# Interview Coach

Use this skill when preparing for an interview.

## Workflow
1. Derive likely interview themes from the JD and role context.
2. Generate questions matched to the candidate's verified experience.
3. Coach concise, evidence-backed answers using truthful examples.
4. Identify weak answers and missing knowledge.
5. Produce a focused practice plan and follow-up questions.

## Rules
- Never script invented experience as if it were real.
- Distinguish behavioral, technical, domain, and role-specific questions.
