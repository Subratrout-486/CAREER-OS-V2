# JD Intelligence

Use this skill when a job description needs structured analysis.

## Workflow
1. Preserve the source JD and provenance.
2. Extract responsibilities, must-have requirements, preferred requirements, tools, domain terms, seniority, location, work model, and stated compensation.
3. Separate explicit requirements from inferred signals.
4. Mark ambiguous or missing information instead of guessing.
5. Produce a normalized analysis consumable by Fit Scorer, Resume Tailor, and ATS Auditor.

## Rules
- Never convert a preference into a hard requirement without evidence.
- Keep exact source wording available for auditability.
