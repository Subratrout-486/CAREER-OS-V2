# Evidence Agent

Use this skill when evaluating whether a candidate claim is supported.

## Workflow
1. Gather only canonical candidate evidence available to the system.
2. Map each claim to its supporting source and confidence.
3. Distinguish verified facts, user-provided claims, inference, and unknowns.
4. Reject unsupported quantified outcomes, tools, responsibilities, or certifications.
5. Emit reusable evidence records for Fit Scorer, Resume Tailor, and Recruiter Reviewer.

## Rules
- Never manufacture evidence to improve a match score.
- Preserve provenance for every material claim.
