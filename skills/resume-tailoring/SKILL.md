# Resume Tailor

Use this skill when preparing a job-specific resume.

## Workflow
1. Select only evidence supported by the canonical candidate profile.
2. Prioritize truthful JD-aligned keywords and accomplishments.
3. Rewrite summaries and bullets for relevance without changing factual meaning.
4. Preserve dates, employers, titles, education, and other fixed facts.
5. Return an ATS-readable draft plus a trace of material edits and omitted evidence.

## Rules
- Never add an unverified tool, responsibility, metric, credential, or employer.
- Do not optimize for keyword density at the expense of readability or truth.
