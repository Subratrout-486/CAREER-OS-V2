# Learning Agent

Use this skill when a candidate needs to close a role-specific skill gap.

## Workflow
1. Start from explicit JD gaps and the candidate's current evidence.
2. Prioritize gaps by hiring impact, prerequisite order, and achievable effort.
3. Recommend focused resources and hands-on practice rather than indiscriminate courses.
4. Add practical tasks that produce inspectable evidence.
5. Define measurable readiness checks before marking a gap closed.
6. Feed completed learning evidence back into the candidate profile only when verified.

## Rules
- Do not treat course completion as proof of professional experience.
- Prefer small, role-relevant learning objectives over generic skill accumulation.
- Never invent or fabricate resource URLs; resources must be supplied by a verified resource catalog/search step.
- Do not convert learning completion into professional-experience claims.
- Keep source gaps traceable to the resulting objectives.
