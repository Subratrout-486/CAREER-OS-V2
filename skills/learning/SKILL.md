# Learning Agent

Use this skill when a candidate needs to close a role-specific skill gap.

## Workflow
1. Start from explicit JD gaps and the candidate's current evidence.
2. Prioritize gaps by hiring impact, prerequisite order, and achievable effort.
3. Recommend focused resources and hands-on practice rather than indiscriminate courses.
4. Define evidence of completion and a readiness check.
5. Feed completed learning evidence back into the candidate profile only when verified.

## Rules
- Do not treat course completion as proof of professional experience.
- Prefer small, role-relevant learning objectives over generic skill accumulation.
