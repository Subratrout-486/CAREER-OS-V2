# Candidate Source of Truth

## Evidence policy

This file is a canonical evidence boundary for resume and interview workflows.

- **VERIFIED**: explicitly confirmed by the candidate or directly demonstrated by a candidate-owned project/repository.
- **UNVERIFIED**: present in an old resume or generated artifact but not explicitly confirmed.
- **EXTERNAL RESEARCH**: role/company research used only to generate verification questions; never treated as candidate experience.
- **REJECTED**: claims that must not be used.

Only VERIFIED evidence is automatically eligible for resumes, fit scoring, recruiter review, or interview answers.
